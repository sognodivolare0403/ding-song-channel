# 丁颂 · 持续发颂

非官方个人主题网站，基于丁颂吧当前公开可访问的 21 个主题与可加载回复制作。

线上网站：[ding-song-channel.vercel.app](https://ding-song-channel.vercel.app/)。

## Vercel 部署

当前 Vercel 项目名为 `ding-song-channel`。`vercel.json` 已声明静态站点部署配置：不运行安装与构建命令，直接发布 `dist/`。

本仓库包含当前已上线版本的网站源码、图片、逐帖资料与阅读报告；Vercel 本地关联信息与登录凭据不纳入仓库。

## 查看

使用任意静态网站服务器提供 `dist/`，或者直接打开 `dist/index.html`。无框架、无安装步骤，全部资源本地随附。

本地预览：`python -m http.server 5173 --directory dist`，随后访问 `http://127.0.0.1:5173`。
